# Tideshore / 潮汐小镇

Tideshore 是一个基于 C++ 和 Qt 开发的 2D 像素风海边便利店模拟经营游戏。

玩家需要在每日营业前进行商品采购、价格设置和员工安排，在营业过程中观察经营表现，并在每日结算后根据收益、客流和商品销售情况进行店铺升级。

## 技术栈

- C++
- Qt
- CMake
- Pixel Art UI

## 主要功能

- 启动页与主流程页面切换
- 营业前准备
- 商品采购与价格设置
- 营业中模拟
- 每日经营结算
- 店铺升级
- 员工管理
- UI 音效反馈
- 本地存档系统

## 项目结构

- Data：数据结构与基础配置
- Logic：核心经营逻辑
- Interaction：Qt 页面与交互逻辑
- assets：图像、音效等游戏资源
- config：配置文件
